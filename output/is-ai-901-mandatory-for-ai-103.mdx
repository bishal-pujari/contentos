# Is AI-901 Mandatory for AI-103? 

This question comes up constantly: do I need to take AI-901 before AI-103?

Short answer: **No.** AI-901 is not a prerequisite for AI-103.

Microsoft does not require fundamentals exams for associate-level certifications. You can book AI-103 directly without ever sitting AI-901.

The longer answer is more useful: whether you *should* take AI-901 depends on your background, not on any exam requirement.

---

## The Official Prerequisite Position

Microsoft's official stance is clear: AI-901 is not a prerequisite for associate or expert-level certifications.

| Exam | Prerequisite |
|------|--------------|
| AI-901 (Azure AI Fundamentals) | None |
| AI-103 (Azure AI Apps and Agents Developer Associate) | None. AI-901 is **not** required. |

The AI-901 exam validates foundational AI knowledge. It is designed for both technical and non-technical backgrounds. It can be used as preparation for role-based AI certifications but is not a prerequisite.

Microsoft Learn explicitly states that AI-901 is "highly recommended if you're new to AI and machine learning" but not mandatory.

AI-901 takes 15-40 hours of study and costs $99 USD.

## Can You Skip AI-901?

Yes. AI-901 is not a prerequisite. You can skip it completely.

The question is not whether you can skip it. The question is whether you should.

**Skip AI-901 if:**
- You already understand AI concepts, generative AI, and Azure AI services
- You have Python experience
- You have built applications using APIs and SDKs
- You want to go straight to the associate-level credential

**Take AI-901 if:**
- You are new to AI or machine learning
- You need to build foundational vocabulary before tackling agentic AI
- You want a confidence-building first exam before the harder one
- You are in a certificate program that includes both

AI-901 is accessible to anyone with basic computing familiarity. AI-103 targets software engineers comfortable with Python who have experience using APIs and SDKs to build cloud solutions. The gap between them is significant.

## How to Test Your Python Readiness for AI-103

AI-103 is a developer exam. Python fluency is assumed.

The official study guide states: "You should have experience developing apps by using Python and should be familiar with general AI, generative AI, and Azure services features."

Here is how to test whether your Python is ready for AI-103:

| Readiness Check | What to Test |
|-----------------|--------------|
| Foundry SDK basics | Can you read and understand code that creates a Foundry project, deploys a model, and configures a connection? |
| Function tools | Can you define a function tool that an agent can call, with proper schema definitions? |
| Semantic Kernel | Can you identify what a plugin, kernel function, and planner do in a code snippet? |
| RAG pipeline | Can you follow code that ingests documents, creates a vector index, and runs a hybrid search query? |
| API calls | Can you read code that makes authenticated API calls to Azure AI services? |

**Practical test:** Find a short Python snippet using the Foundry SDK or Semantic Kernel. Can you identify what it does within 15-20 seconds without tracing each line? If not, your Python is not ready.

The exam includes code-completion items against the Python Foundry SDK. You need to read and reason about real code, not pseudocode.

If Python is a weak point, AI-103 will be significantly harder. Consider building Python skills through Microsoft Learn's Python learning paths or general Python courses before attempting AI-103. AI-901 does not teach Python and will not close this gap.

## The Study Time Difference

| Exam | Study Time | Difficulty |
|------|------------|------------|
| AI-901 | 15-40 hours | Easy |
| AI-103 | 40-100 hours | Medium to Hard |

AI-901 is a fundamentals exam. No labs are required. AI-103 is an associate exam where hands-on labs are non-negotiable.

If you take AI-901 first, you add 15-40 hours of study and $99 USD. That time is not wasted if you need the foundation. If you already have the foundation, it is redundant.

## Do You Get a 50% Voucher Like AWS?

Microsoft does not offer a blanket 50% discount on every exam. But there are legitimate ways to get exam discounts:

| Discount Source | Details |
|-----------------|---------|
| Microsoft Virtual Training Days | 50% discount applied to your Microsoft Learn profile after attending |
| Microsoft Learn Cloud Skills Challenge | Complete specific learning modules within a timeframe to receive a 50% exam discount |
| Conference vouchers | Events like Web Summit sometimes offer 50% certification vouchers |
| Authorized exam vouchers | Can reduce exam cost by up to 25% |

The 50% discount from Virtual Training Days takes about 5 business days to appear in your profile after the session. It appears automatically at checkout when you schedule the exam.

You can apply these discounts to either AI-901 or AI-103. The voucher is not exam-specific in most cases.

## The Honest Bottom Line

AI-901 is not mandatory for AI-103. You can skip it without any penalty.

The decision is purely about your current skill level. If you already understand AI concepts, have Python experience, and have built applications with APIs and SDKs, go straight to AI-103. If you are new to AI or need to build foundational vocabulary, AI-901 is a worthwhile investment.

Microsoft's exam discount programs apply to both exams. The 50% voucher from Virtual Training Days or Cloud Skills Challenges can be used for either.

Do not take AI-901 because you think you have to. Take it because you genuinely need the foundation.
